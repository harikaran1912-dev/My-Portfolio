HARIHARAN PORTFOLIO — HTML, CSS & JAVASCRIPT

FILES
- index.html: portfolio page content
- style.css: dark theme, layout, and responsive styles
- script.js: mobile menu and current year

HOW TO RUN
1. Extract this ZIP file.
2. Open the Hariharan-Portfolio folder.
3. Double-click index.html to open it in your browser.
4. For easier editing, open the folder in Visual Studio Code.

IMPORTANT — CUSTOMIZE BEFORE PUBLISHING
1. In index.html, replace your.email@example.com with your real email address.
2. Replace the GitHub and LinkedIn links with your real profile URLs.
3. Replace the sample project links with your own GitHub repository/live website URLs.
4. Add your actual resume PDF to this folder and name it Hariharan-Resume.pdf.
5. Update project descriptions so they match projects you have really built.

GITHUB PAGES
1. Create a GitHub repository named Hariharan-Portfolio.
2. Upload index.html, style.css, script.js, and your resume PDF.
3. In the repository, open Settings → Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish the site. Copy the URL shown in Settings → Pages.

This is a starter template. The resume file is not included because your actual resume was not provided.
